# Formation documents

Put the company's actual certificate of incorporation, bylaws, initial board consent, and EIN confirmation here. Keep original signed or issued files intact. Use descriptive filenames; `certificate-of-incorporation.pdf`, `bylaws.pdf`, `initial-board-consent.pdf`, and `ein.pdf` are examples, not required names.

This starter contains no formation documents. Your agent should ask for them and use [CHECKLIST.md](../CHECKLIST.md) to report anything missing or unconfirmed.
