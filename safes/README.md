# SAFE documents

Keep each investor's signed SAFE in a directory named for its OCF `security_id`, for example `safes/safe-yc-mfn/`. Store any side letter or related approval beside it. Match each document to its `TX_CONVERTIBLE_ISSUANCE` in `minicap/Transactions.ocf.json`; compare holder, investment amount, date, and conversion terms.

The example contains three fictional SAFE issuances, but no signed SAFE PDFs. When turning the starter into your company's record, remove the fictional instruments and add only confirmed investments and their supporting documents.
