# Option plan documents

If the company has an option plan, keep the plan and its adoption approval here. Put grant documents in `grants/` as grants are made, with filenames that identify the holder or security. Compare the plan reserve and recorded grants with `minicap/StockPlans.ocf.json` and `minicap/Transactions.ocf.json`.

The fictional OCF package has an unallocated option plan, but no supporting plan or approval PDF is included in this starter.
