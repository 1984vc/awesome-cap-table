# Founder documents

Create a directory per founder, named for the corresponding OCF stakeholder ID, such as `founders/founder-alex/`. Put that founder's stock purchase agreement and IP assignment there. If an 83(b) election applies, keep the election and separate proof of filing under `83b/`.

The sample OCF package names two fictional founders, but no founder documents are supplied. Ask the founder who actually founded the company, whether each stock grant is restricted or vests, and what documentation is available. Do not treat an election form as proof that it was filed.
